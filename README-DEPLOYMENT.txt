AL BIDAYA QURAN ACADEMY – WEBSITE REDESIGN
================================================

This package contains the redesigned English-only responsive website.

Brand:
- Al Bidaya Quran Academy
- Tagline: Learn the Quran. Build a Lifelong Connection.
- Main Office: Calicut, Kerala, India
- Qatar: Coming Soon
- India WhatsApp: +91 62381 59862
- Theme: Navy Blue, White & Gold

Included:
- Responsive home, about, courses, learning method, pricing, branches, admissions and contact sections
- Existing course images and logo retained from the supplied ZIP
- Existing monthly base prices retained: QAR 120, QAR 220 and QAR 290
- Pricing currency selector: INR, USD and QAR
- INR/USD display conversions are indicative estimates; live payment checkout is not yet connected
- Admission enquiry form opens WhatsApp with a prepared message
- Front-end portal demonstration for Student, Parent, Teacher and Admin roles

IMPORTANT – PORTAL BACKEND:
The portal sign-in in this package is a front-end demonstration only. It does not authenticate users or store data securely.
Before real public use, connect a backend (for example Supabase or Firebase), configure secure authentication and role-based access,
create database tables and access policies, and implement secure student/parent/teacher/admin workflows.
Do not collect real student records through the demonstration portal.

Deployment:
1. Upload the contents of this folder to your hosting provider or deploy it as a static site.
2. Keep index.html and all image assets in the same directory.
3. Configure your domain and HTTPS.
4. Test the admission WhatsApp link and contact details.
5. Complete backend integration before enabling real portal accounts.
6. Connect a payment provider that supports INR, USD and QAR settlement/checkout before accepting payments. The current currency selector changes displayed prices only; it does not process payments.

Content verification:
Claims such as student totals, teacher totals, qualifications, class frequency, discounts, and guaranteed services
were not retained as factual claims because they require management verification.
